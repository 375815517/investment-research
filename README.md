# 研习 · AI 协同投资研究工作空间

长期研究企业、行业与市场，持续积累资料和行情；通过可追溯的分析、预测、评估和复盘，改进研究方法、因子与模型。

整个仓库根目录就是人和 AI 的工作入口。AI 提供理解与研究组织，平台执行明确口径的计算并保存事实，可视化呈现同一结果。

## 当前状态

当前仅完成架构沉淀、目录骨架与旧内容暂存。空目录使用 `.gitkeep` 保留，尚未实现新平台、Skills、初始化命令或自动研究流程。
