# 来源观测指标字典

每个 `metric-id/v1.json` 通过 `MetricDefinition` 校验，绑定经济含义、合法单位、存量/流量、期间及维度。维度值在观测中显式保存，不拼接进指标名；同一收入指标可以有集团或分部范围，但不得混加。

`financial-observations` 与 `operating-observations` 只接受来源实际披露，不保存平台推算。旧 `financial-facts` 不自动升级为 v2；补充维度或时间证据需新增经过复核的版本，不能重写原记录。

`basis` 保存来源脚注的具体口径。字典的相同指标名不能替代语义复核；费用的正负号、现金流量项目范围、股票类别、业务分部改组均须看原件。经营统计的出货、交付、活跃用户和连接设备具有不同统计总体。

新指标先新增版本化定义和正负样例，再提交观测；不把任意字符串当已核实金融定义。`allow_negative` 不用于猜测未披露数值，缺失必须保留状态、原因与原件。
