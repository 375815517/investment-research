# 小米输入需求清单

- acquired-samples.json：仅验证已取得的有限样本。
- requested-inputs.json：保留用户提出的市场核心字段，不删除未取得项。
- annual-summary-history.json：逐年、逐字段、指定当年年报来源检查2018–2025年四项年度损益摘要，防止五年20行掩盖早期缺年。它不代表完整财报；资产负债、现金流、归母利润/EPS、分部和季度仍是独立缺口。

以上是可执行 AuditInputsRequest。minimum_records 是样本门槛，不是历史完整率；年度覆盖使用每个年度独立要求。daily-prices 的2048条门槛只能检查计数，交易日精确覆盖另用有依据的日历检测。政策、新闻、行业报告没有权威全集时，不能以样本数量宣称完整。新来源补齐后应重跑同一需求，保存新的运行记录，保留旧报告。
