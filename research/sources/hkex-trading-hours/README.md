# 香港交易所证券交易时段

来源：https://www.hkex.com.hk/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en 。2026-10-30 取得 HTML 原件，经统一 import 归档。

核实周一至周五交易（公众假期除外），正常交易日收市竞价于 16:08–16:10 HKT 随机结束。预期清单的 16:25 到期时间是研究方增加 15 分钟容忍度，不是供应商服务承诺。半日市须另核实，不能套用正常收盘时间。

当前有限窗口无证券停牌证据；缺价时不能自动豁免为停牌。网页公开时间未知，不是历史交易所公告快照。
