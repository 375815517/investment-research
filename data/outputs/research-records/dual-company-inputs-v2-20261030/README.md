# 双企业财务原始观测与证据

本目录保存小米（01810/HKD）及腾讯（00700/HKD）的提取规格、候选、独立复核、来源发现和准入回执。它是过程证据目录，不是正式观测数据库。正式原件在 `data/inputs/source-files/`，通过平台准入的观测在对应公司的 `financials/` 目录；禁止把本目录候选直接当成已注册事实。

## 文件与期间

| 文件名片段 | 来源和期间 | 取值列 |
| --- | --- | --- |
| `YYYY-financial` | 正式年报，当年完整年度及年末余额 | 当年列 |
| `YYYY-interim-financial` | 正式中报，1–6 月及 6 月末余额 | 损益四列中的第三列；余额、现金流的首列 |
| `YYYY-q2-financial` | 正式中报直接披露的 4–6 月损益 | 四列中的首列 |
| `YYYY-h1-announcement-financial` | 更早的半年业绩公告，1–6 月及 6 月末余额 | 损益第三列；余额、现金流首列 |
| `YYYY-q2-announcement-financial` | 同一半年公告直接披露的 4–6 月损益 | 四列中的首列 |
| `YYYY-q1-announcement-financial` | 一季度业绩公告，1–3 月及 3 月末余额 | 当年列 |
| `YYYY-q3-announcement-financial` | 三季度公告的 **1–9 月累计**损益、现金流及 9 月末余额 | 损益第三列；余额、现金流首列 |
| `YYYY-q3-financial` | 三季度公告直接披露的 **7–9 月单季**损益 | 四列中的首列 |
| `YYYY-q4-financial` | 年度业绩公告中直接披露的 **10–12 月单季**管理层比较表 | 当季列；腾讯 EPS 来自首页 IFRS 栏 |
| `opening-cash` | 年报现金流量表直接披露的期初现金 | 当年期初，记为 1 月 1 日存量，不覆盖上年 12 月 31 日 |
| `annual-share-denominators` | 年报 EPS 附注的基本／稀释加权平均股数 | 当年列；不是期末发行股数 |
| `annual-capital-cash` | 原文披露范围对应的资本现金支出 | 当年列；不把更宽范围冒充仅购买物业设备 |

`*-spec.json` 固定原件 ID、准确物理页、唯一行表达式、列号及业务语义；`*-candidates.json` 保留原文、源值与单位。`*-review.json` / `*-independent-review.json` 由其他代理核对原件，绑定候选及原件哈希。`reviewed-financial-admissions.json` 记录每次准入结果，包括先前的拒绝记录；应按文件及哈希查看后续成功回执，不能把历史拒绝当作最新状态。

## 可重放提取与人工语义审核

```bash
uv run python scripts/extract_report_candidates.py \
  --spec data/outputs/research-records/dual-company-inputs-v2-20261030/xiaomi-2024-financial-spec.json \
  --output /tmp/replayed-candidate.json
```

脚本只生成候选，不授予准入。正数、括号负数、精度均取自原件；破折号不会自动变成零。`extraction_mode` 可显式选择普通或布局文本；例如腾讯 2018 年三季度现金流普通文本把 `(2,669)` 拆开，布局文本保留了真实数值，规格明确采用后者。`evidence_excerpt` 只用于保存经核准的布局连续引用，且仍必须在该物理页中出现。

`extractor-versions/<sha256>.py.txt` 保存被候选引用的提取器完整源代码版本，可用 Python 执行该快照重放。代码格式更新不篡改已审核候选的历史 `script_sha256`。布局修复报告记录普通文本与布局文本仅空白差异的映射；数值、单位、期间和维度未因修复改变。

## 保留的会计与时间边界

- 小米年度金额多为人民币千元；腾讯年度金额为人民币百万元；两家公司 Q4 管理层表均为百万元。EPS 是人民币／股。原单位和源精度不被静默统一。
- 主表带符号费用和附注正数费用金额都保留原符号。跨表比较需显式转换；净财务收益／成本、利息相关费用和总财务成本是不同指标。
- 小米早期应收账款与后来含票据的应收款范围不同；借款按流动／非流动分类，不自动等同合同原始期限。腾讯借款不自动包含单列的债券。
- 腾讯 2023 年年报调整经营利润列报；原来包含的投资损益和利息收入被移到经营利润之后。原年度及中期原报数值不被后续比较栏覆盖。
- 正式中报与更早的业绩公告分别保存来源及公开时间。单独的报告版／公告版需求规格显式选择来源；不能把正式报告的公开日提前，也不能靠同值去重掩盖两个版本。
- Q4 是原件直接披露的单季值，没有把“年度减前三季累计”伪装为原始披露。小米 Q4 表未找到的归母利润、基本／稀释 EPS、单独总财务成本，以及其他原件只列净财务项的字段，仍由完整需求规格保留缺口。
- 公开时间采用有证据的日期精度及保守可用上界，详见 `../publication-review-v2-20261030/`。报告期末不是公开时间，也不意味着整份报告当时已可知。

来源目录可能同时返回股东大会投票结果等非财务公告。`quarterly-discovery-scope-exclusions.json` 及任务的追加事件保存排除理由；保留原件不等于把它计入财务覆盖。

## 股本冲突隔离与最终任务状态

新增年末已发行股本与类别股本共有 20 条候选，19 条通过独立审核后准入。小米 2023 年报物理页 309 的合计表披露 25,073,427 千股，而同页 A/B 类叙述合计为 25,082,426,507 股，差 8,999,507 股，超过舍入误差。该候选已在平台明确拒绝，**没有进入正式观测**；原件、候选与两组数均保留在 `independent-issued-share-capital-review.json` 和 `xiaomi-2023-share-capital-quarantine.json`。在找到可核实的解释或更明确来源前，不用于市值、每股指标或估值分母。

`registered-observation-summary.json` 保存最终真实统计：财务观测 3,073 条、经营观测 22 条；其中财务包含正式中报和更早公告的来源版本，不能解释为 3,073 个互不重复的经济事实。226 份财务候选文件中，225 份已准入，唯一未准入的是上述冲突股本。

`financial-acquisition-task-closures.json` 保存 21 个原件任务的最终回执：11 个完成，10 个带明确排除理由完成；93 个任务项验证，21 个任务项排除，没有未审核原件项。任务验证只证明指定观测子集完成处理，完整字段可用性仍以固定需求规格的逐键审计为准。
