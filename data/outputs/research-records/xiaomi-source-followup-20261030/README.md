# 小米来源补采与历史覆盖核验

本轮沿共享 import → prepare → validate → review → ingest → coverage 流程新增32条观测。

- `hkex-daily-admission.json`：2026-10-29官方日报原件、4条量额及卖空观测与准入回执；同日同counter分子/分母明确，未把计算比率写成来源披露值。
- `annual-discovery.json` / `index-import-receipts.json`：2018–2025官网年份索引、原件链接和索引归档，不把发现链接视为下载完成。
- `annual-admissions.json`：2018–2024七份完整年报归档及28条当年度财务值；结合已有2025年报，已取得2018–2025年度原件。
- `price-crosscheck.json`：2026-10-29腾讯收盘/最高/最低/成交量与HKEX同日核对一致；仅单日检验，不升级全历史口径。
- `network-probes.json`：HTTP尝试、成功与失败证据摘要。2026-10-30日报404，不混用29日分母。
- `verification.json`：逐来源实际查询、当前计数与剩余覆盖限制。财务52条是多来源观测数，不是52个独立指标或52期。

2018–2024各年仅提取收入、毛利、经营利润、年度利润，均为合并口径、人民币千元。年度利润不等同归母利润或非IFRS调整利润。当前公开时刻仍未知，网站迁移路径不能证明原公告时间；不冒充可直接用于历史时点回测。所有既有批次保持不变。
