# 输入结构 v1 封版决定

日期：2026-10-30。状态：采纳。范围：输入数据，输出结构不变。

依据：软件工程、行业分析、数仓、基金管理、架构、开发六种视角评审，以及用户对可读性、主证券和企业入口的确认。

采纳 [输入数据结构基线 v1](../architecture/input-data-baseline.md)：共享原件、独立采集记录、业务结构化数据；企业自身资料归企业，行业/政策共享并通过证据关系关联；公司入口唯一，不设 subjects；每公司先确认一只主证券，不提前设置 listings；股票行情在 markets/prices；来源与数据集定义分开。

原因：一份年报可支持多个业务记录，一批行情可包含多只证券；采集批次与查询分区不可绑定。可读性通过具体命名、字段说明和导航实现，不通过复制或混放原件实现。历史研究区分事后解释、时点重建与当时实际信息复现。

代价：需要 ID 解析、元数据与派生导航；不得依赖目录猜测版本。实现尚待建设，不以文档或目录存在声称自动执行。

后续：先以小米验证单份原件复用、行情批次、政策共享、解析修订、失败处理与历史时点。改变此合同需新增决定和迁移策略。
