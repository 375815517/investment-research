# 002：保留供应商原始口径，显式检测需求覆盖

日期：2026-10-30。状态：已实现。范围：输入基线 v1 的兼容扩展，不涉及指标和收益计算。

## 原因

基线希望取得未复权行情，但真实供应商接口的调整方法和成交量单位未必具有可核实说明。将所有响应强行标记 unadjusted/shares 会制造事实；只允许该标签又会丢失已取得且有研究价值的来源观测。

## 决定

日线允许明确标记 provider-native 价格和成交量单位；这表示保存来源数值，调整算法/量单位尚未核实，不表示已转换。unadjusted/shares 仍保留原有含义。需要未复权行情的需求不能被 provider-native 记录满足。业务键和覆盖选择纳入价格口径，来源间不静默合并。后续核实或转换时新增有证据版本，保留最初观测。

该扩展不授权基于未知口径计算可比收益或成交额，不增加任何预测或因子功能。API、网页、Skills必须显示口径及限制。

来源归档配置区分明确禁止、未知和用户授权的有限研究采集。公开可访问与开源许可不同，用户授权也不创造再分发权；research-only 记录具体研究用途与限制，不标成开放许可，不绕过认证、付费或技术访问限制。公开发布前须另核对来源条件。

## 检测事实

交易日历仍在 markets/calendars，增加有证据的证券交易状态 markets/trading-status；公司披露预期放 companies/<id>/reporting-calendar。预期记录固定覆盖区间、逐日/逐报告项目、到期时间、信息时点和原件引用。节假日与收盘安排从官方来源核实，未知停牌不得自动当作休市。

本次小米验收可以声明有限日期窗口满足“供应商原始口径”需求，不能扩大成“全部历史未复权数据完整”。未来新增来源仍走相同合同和检测过程。
