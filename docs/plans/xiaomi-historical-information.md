主证券 01810/HKD，上市日期 2018-07-09，由小米官方公司介绍核实。日行情请求到 2026-10-29，查询可用2048个交易日；逐段原件、失败回执与补采结果已保存。完整记录见[行情验证](../../data/outputs/research-records/xiaomi-listing-history-20261030/verification.json)。价格与量仍为来源原始口径。

默认查询按港交所公告排除2023-07-17全天休市占位值，原件与原批次不删除。其余日期与 exchange_calendars 4.13.2 的XHKG日历模型比较无缺口；模型比较不等于每个历史日期均经官方公告独立核实。本次不纳入2026-10-30当日行情。

## 同步含义与检索顺序

同步是围绕同一研究区间生成各数据集需求、并行或顺序获取、分别核验，最后汇总覆盖；不是把每个交易日机械配一条新闻，也不是所有渠道必须同频更新。

每条资料保存业务期间/事件日期、发布时间及精度、首次观察/采集时间、生效区间、修订关系和原件定位。共享政策和行业资料独立归档，企业入口通过有依据的关系引用。历史时点研究先筛公开可知性，不能用后续报道解释当时已知的信息。

流程：对象与区间 → 各渠道覆盖检查 → 可访问来源获取 → 原件归档 → 候选提取 → 去重/口径/证据核验 → 入库 → 同需求复查。付费或删除的历史资料记为缺口，不绕过访问限制。历史全文搜索摘要不能代替原件。

## 分批验收

1. 行情全区间与异常核验（本次已执行）。
2. 按年度枚举IR/HKEX的上市以来财报及公告原件，报告缺期；再选择明确所需财务字段整合，不能把PDF下载成功等同所有表格已核验。
3. 以一个明确业务、地区和历史区间验证政策/新闻/行业三类接入；归属、时间和去重稳定后扩展历史。
4. 网页和AI按渠道显示取得范围、未结构化原件、待核验、不可访问与剩余缺口，不显示笼统“全部数据已同步”。

多源样本已实施，详见[多源验收](../verification/xiaomi-multi-source.md)；上市以来各期资料覆盖仍待补齐，不以样本验证替代历史完备性。
