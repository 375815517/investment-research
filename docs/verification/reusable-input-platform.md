# 可复用输入平台验收

日期：2026-10-30（Asia/Shanghai）。本记录对应[已批准计划](../plans/reusable-input-platform-implementation.md)，工程实现、来源覆盖和研究用途分别验收。工程检查与真实数据回执分别列示；输入充分性仍按具体用途判定。

## 架构和实际变化

维持 `ai/`、`apps/`、`packages/`、`research/`、`data/` 的边界。四个公共包承担领域合同、确定性执行、来源接入及Git文件存储；新公司通过登记、来源映射和版本化需求进入，不在引擎增加公司分支。

- 维度化财务、经营、公司行动、基准合同；v1财务保留可读。
- 指标及尺度目录，逐对象、期间、字段、维度、版本的精确需求；跨需求比较组与显式单位换算。
- 原件只存一份；原公开时间只追加修订，分别处理历史重建和当时实际观察。
- 来源能力与对象映射分开；发现、分页、获取、提取、审核、准入、跳过与恢复保留Git任务记录。
- CLI、API和网页复用同一服务；AI规范与Skills提供统一操作流程。
- 单次准入校验复用已验证读取视图；不跨请求信任缓存，保留原件哈希和STALE保护。实测及边界见[决定005](../decisions/005-input-platform-scaling.md)。

## 财务和公开时间

两家公司2018–2025年报、2018–2026中报已取得；Q1/Q3/Q4按实际披露制度和上市范围分别处理。提取器先复用原件，再生成带页码、原文、列、期间和脚本摘要的候选；独立审核绑定候选摘要，排版修正后重新审核。

资本支出按来源范围区分；PPE、无形资产、土地、在建工程或投资物业不能隐式互换。年度core v1保留纯PPE门禁；v2明确按公司及年度的原披露范围要求，其他键不减少。v2来源完整不证明跨公司可比性。腾讯历史利息及相关费用不替代未取得的同口径总财务成本。

正式中报与更早业绩公告分别归档、提取和选择，不能把较晚报告的日期提前。公告与中报的同值事实也保留不同来源版本，由需求明确来源，不能放宽匹配数量隐藏多义。

目前101份财报和公告的日期证据经过核验，303条PIT查询检查保守上界前、上界后和live模式；根行情停市公告日期验证另列，不混入该财报计数。

时间验证回执在 `publication-review-v2-20261030/`，财务规格、候选、审核与逐批准入在 `dual-company-inputs-v2-20261030/`。年度、季度最终精确覆盖与应用验收在 `dual-company-input-profiles-20261030/`。

## 可恢复性和边界

规范化与冻结分别固定来源、元数据修订、辅助证据、指标目录、尺度、参数及实现。单位换算可确定性重放；累计转单季及两时点平均已有底层合同与负例验证，尚未作为独立CLI/API操作。

输入包的 `verified` 只表示固定版本一致，`frozen` 不会把 `limited/blocked` 改为 `ready`。更换来源、方法或代码需要新运行版本。新增资料不修改旧预测或历史输入包。

Codex/CodeBuddy文件投影已同步；宿主自动发现与实际调用没有据此宣称全部验证，Hook、MCP、定时任务及预测/因子研究不在此次交付范围。

## 工程与恢复验收

完整检查通过366项测试、Ruff、mypy、离线演示及7个workspace包构建。最终输入包在 `data/outputs/research-records/verified-release-inputs-20261030/`，包含ready、limited及blocked的真实状态；固定版本校验通过不会改变用途状态。实现按源码摘要去重归档，旧开发期输入包也已保全对应源码，未来可按原版本恢复。

新克隆验收发现并修复了公司行动新增可选付款精度字段对旧任务幂等恢复的影响：比较视图归一等价默认值，真实日期变动仍冲突，旧批次字节未改。验证和复核各自使用独立校验快照，恢复后不依赖原机器候选缓存。失败及修复回执保存在 `recovery-verification-20261030/`。
