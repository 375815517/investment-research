## 核查结果与阻塞

[已取得样本清单](../../research/coverage-policies/xiaomi-multi-source/acquired-samples.json)为14项，实际audit为14/14。保留所有所提字段的[完整请求清单](../../research/coverage-policies/xiaomi-multi-source/requested-inputs.json)为19项，实际audit为14/19 partial。

| 缺口 | 原因与解除条件 |
| --- | --- |
| short_sale_ratio | 已有卖空金额，缺同日同counter可靠总成交额分母；取得同口径来源后才能报告比例 |
| reported_short_position_ratio | 须申报淡仓人口/门槛明确，但对应报告日股本分母未核实；不能拿另一时点或另一股类相除 |
| long_position_ratio | 未定义全市场多头统计对象，未找到直接来源；需指定披露群体/工具/时点，不能用1减卖空比例 |
| free_float_ratio | 供应商Float股类范围/自由流通方法不明；需匹配分母与生效日，不用公众持股合规声明代替比例 |
| turnover | 官方总成交报价候选404，另一页面只返回模板；不以OHLC乘量造总成交额 |

样本需求全部满足不等于完整历史新闻、政策、淡仓、估值均齐全。当前两类新数据没有无界自动发现或按日全历史补采器。缺口和失败证据已保存，未伪造null为零或以“来源未披露”替代“平台没取得”。

## 多角色验收与修复

- 软件工程：四个有限合同、共享数据集注册/业务键、强制复核、CLI/API/web共用服务，新增只读audit_inputs。
- 行业分析：政策适用与受益推断分离；出货与零售、订单与交付、公司声明与独立事实分离。
- 基金研究：卖空流量、淡仓存量、净多空不同；PE利润/时点、流通股类及分母不能偷换。
- 数据治理：明确样本、来源覆盖、未取得原因；新闻不能声称全网全集。
- 独立审查：逐条核对16市场候选、20财务值、2股类数量与7声明；复现并促成时区等价去重、未来分母泄漏修复。新增业务按UTC时刻日/来源纯日期查询，旧记录读时兼容不重写。

完整本地检查通过：**147项测试**、Ruff/格式、mypy、离线CLI闭环和7包构建。真实浏览器显示18市场行、2政策行，样本14/14和请求14/19；新类自动补采按钮禁用，未出现脚本异常。Codex显式读取Skills后的真实CLI调用通过，原生宿主自动发现和CodeBuddy真实调用仍未验收。

官方年报精确公开时刻未知，严格历史截止查询保守排除；BBC取已捕获文章的dateModified作为版本可知时间，政府页面取明确发布时间；Omdia只有公开日期未补造时分。远程CI运行结果须另看，当前未宣称通过。
