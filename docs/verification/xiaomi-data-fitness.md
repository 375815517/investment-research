# 小米输入数据闭环与分析适用性

日期：2026-10-30。本轮范围是原始资料、整合输入和数据质量评估，不包括预测、投资因子或交易执行。原件、准入回执、标准化记录和本报告均随Git保存。

## 结论

已验证小米真实数据的发现/获取 → 原件归档 → 候选提取 → 结构与证据校验 → 复核 → 入库 → 查询 → 覆盖与用途评估闭环。**闭环能力通过，不等于全部历史资料齐全，也不等于已经具备无前视回测或完整基本面分析条件。**

| 输入 | 已取得范围 | 分析限制 |
| --- | --- | --- |
| 日行情 | 2018-07-09至2026-10-29，2048交易日，1条官方休市占位排除 | Tencent provider-native口径；日历模型比对无缺日，2026-10-29与HKEX高低收及量相符，仅单日交叉核验，不证明全历史复权/单位 |
| 年报原件 | 小米2018–2025年度官方原件 | 精确历史公开时刻未知；原件齐不代表季度资料或所有表格已结构化 |
| 财务值 | 52条来源观测，覆盖2018–2025收入、毛利、经营利润、年度利润 | 来源重复/汇总版本分别保留，不是52个指标；缺完整现金流/资产负债、归母利润/EPS、分部与季度 |
| 政策、新闻、行业竞争、公司声明 | 7条可定位声明，政府/BBC/Omdia/年报 | 有界样本，不是全网舆情、完整政策体系或全时期竞争格局 |
| 市场核心观测 | 22条，含SFC两期淡仓、HKEX两日量额样本、股份与供应商PE | 不是每日历史指标序列；同股类、时段、币种、分母须明确 |

来源可靠、原件未变、提取正确、期间完整和适合某用途分别判断。官方资料仍可能只有样本；页面摘要匹配不自动证明语义正确。多角色独立核验见[金融审查](xiaomi-financial-data-review.md)和[工程审查](input-engineering-review.md)。

## 卖空比例与分布

2026-10-29港交所同表01810港币counter：卖空成交额HKD483,583,896，总成交额HKD2,273,256,204；由脚本确定性计算约 **21.2727%**。它保存在[派生验证记录](../../data/outputs/research-records/xiaomi-data-fitness-20261030/short-sale-ratio-validation.json)，标记derived_validation并引用输入，不写成source_reported。

这是当日卖空成交金额占比，不是空头持仓比、净空头占比或看空人数比。不能用1减它得到多头持仓比。2026-10-30总成交日报仍未取得，不能套用29日分母。

须申报淡仓比例和自由流通比例仍缺匹配日期/股类/方法的分母。多头比例及“分布”必须先定义统计总体（例如披露持仓群体或特定工具）、时点、数量/金额权重及分组；当前没有相应完整明细，不生成伪分布。公开市场成交的买卖两端也不等于投资者看多看空比例。

## 系统化调整

1. 四类有限合同共用获取、审核、准入与查询；AI不直接写正式业务数据。原文陈述和平台推断分离。
2. `audit-inputs`检查声明样本；新增逐年逐字段清单，防止五年20行掩盖早期缺年。它不认证全部财报字段或全网资料完整。
3. `assess-inputs`按来源描述、量化比较、历史时点三种用途产生ready/limited/blocked、限制代码和证据引用；CLI/API/web复用同一实现。不生成无依据综合可靠度评分。
4. 原件和批次摘要校验、比例分母、时区等价去重、休市/预期日历依赖证据的历史可知性均落到执行层，修复未来证据泄漏。
5. 发布检查保护Markdown原件和业务事实历史；目录预览2000项上限不再隐藏来源、证券或需求配置。
6. AI Skills要求先覆盖检查、再按用途评估，有限可用必须携带限制；未知不是零，未知公开时点不能进入严格历史输入。

## 用途准入

| 用途 | 判断 |
| --- | --- |
| 阅读并引用上述来源、核对特定政策/新闻声明 | 有限适用，保留来源主张与时点限制 |
| 2018–2025四项年度损益的事后比较 | 有限适用，先选来源版本和单位；不能代表完整财务 |
| HKEX指定日量额、卖空成交占比 | 同日同counter可验证；不外推历史序列或持仓分布 |
| 完整基本面、每日历史PE、流通/多空分布 | 输入不足 |
| 无前视偏差历史回测、因果归因、预测训练 | 目前不能据此宣称可用；公开时刻、口径、基准/公司行动及覆盖仍不足 |

机器评估只是明确规则的检查，不代替金融语义复核；ready仅适用于声明样本和用途，不是投资结论认证。

## 本次最终验收

全项目检查 **185项测试通过**，Ruff、格式检查、mypy（23个源文件）、17步离线CLI闭环及7包构建通过。真实Chromium验证网页完整需求blocked 15/19、年度汇总limited 32/32，API/页面市场22条且无页面异常；[浏览器证据](../../data/outputs/research-records/xiaomi-data-fitness-final-20261030/browser.json)已保存。AI宿主投影同步并验证文件一致；原生发现仍未验收。

稳定数据集上重新执行：已取得样本14/14但来源描述仅limited；完整字段要求15/19、blocked；指定当年年报的逐年四字段32/32，来源描述与有限量化比较limited。2025年末严格历史时点下该年度财务清单0/32、blocked，不能将今天补采的年报当成当时已核验可知。

评估曾因重复扫描原件耗时较长；已实现请求内只读快照，独立请求重新验证摘要，19项需求约0.52秒、32项约0.8秒（本机本次样本，不是性能保证）。回归覆盖跨请求篡改仍被检测、只读快照和返回值隔离，以及半年/全年混频阻断。
