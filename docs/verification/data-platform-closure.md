## 明确能力边界

- 来源价格调整方法与成交量单位未核实，均标记provider-native。有限来源原始观测可以研究，不能替代核实后的未复权/股数数据。
- 当前预期清单仅覆盖已核实窗口；没有自动全年交易日历/证券停牌解析器或全球财报期限推断。窗口外返回unknown，不自动猜测；新增窗口需要有证据的预期登记。
- 财报字段由通用Agent理解并提交，程序负责证据定位与准入；无自动全表语义提取或OCR保证。
- Git保存上述真实数据和执行证据；来源research-only说明不是开放再分发许可。没有自动Git发布服务。
- Codex原生发现、CodeBuddy真实宿主、MCP和Hook仍未验证/未实现；当前可用入口是根规范、显式Skill、CLI和API。
- 不含定时调度、公网认证部署、指标、预测、评估、复盘。

上述能力边界不能表述成“所有来源、历史口径、宿主均完成”。本次完成的是可运行的数据闭环及指定小米真实样本验收；进一步全面历史研究仍需补齐来源口径与历史证据。
